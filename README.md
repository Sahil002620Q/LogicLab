# LogicLab

Interactive digital logic circuit playground built with React, TypeScript, and Vite.

## Features

- Place logic gates, switches, ICs, LEDs, clocks, and a seven-segment display
- Connect component pins with wires
- Simulate basic digital logic
- Export circuit designs

## Development

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Note

This is a logic-level educational simulator, not an electrical SPICE simulator.
